# vector_subtraction

**The rule.** Thread `k` of the launch, for `k` below the length `n`, writes
`lhs[k] - rhs[k]` (binary32 subtraction) to `out[k]`, and nothing else.

**What is proved, for one kernel.** The kernel is the tutorial's (docs/new-kernel.md):
`vector_addition` with `-` for `+`, compiled with Mojo 1.3.0.dev2026112105; the corpus file is
one specialization (float32, one dimension). `MojoProof.Kernels.vsub.correct` is the kernel
theorem (`Kernel.Sound`), generated by one `mojo_kernel` command with a `map2` clause and no
proof lines, for every valid one-dimensional launch and every caller's memory of `Map2.Pre`: the
run is memory safe and race free, and output cell `k` holds `MojoProof.Kernels.vsub.bytes`, the
bytes of the delivered `Model.sub` of the inputs' cells. `MojoProofTest.Kernel.vsub_real` adds
that a finite output is TorchLean's `x - y` at `k` and that its real value is the real
difference rounded to binary32. This is the L3 and the L4 evidence, as for vadd.

**Out of scope.** Other element types and widths, other launch shapes than one dimension, and
the bits of a NaN output.

**Open.** L1: no tracked record of a GPU run of this kernel.
